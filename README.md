# DNA Android Tools — GitHub Actions

Linux-based workspace for Android image and ROM utilities.

## Run
1. Open the repository on GitHub.
2. Select branch `github-actions-tools`.
3. Open **Actions**.
4. Select **DNA Android Tools**.
5. Press **Run workflow**.
6. Choose `check-tools`.

Unpack, repack, resize, and convert are placeholders until their
specific scripts and input/output handling are implemented.
No image is flashed to a device.
